# Rubric: Explanation quality

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Motivating problem | Starts with terms or formula | Mentions purpose vaguely | Makes the original obstacle concrete |
| Mechanism | No causal or logical model | Partial mechanism | Learner can trace why the rule follows |
| Precision | Undefined symbols or conditions | Mostly correct but incomplete | Units, assumptions, and notation are explicit |
| Visual function | Decorative or absent | Labels information | Supports prediction or reconstruction |
| Worked reasoning | Gives answer only | Shows steps without decisions | Exposes why each decision is made |
| Transfer | Repeats the same form | Nearby variation | Direct, disguised, and mixed application |
| Retrieval | Rereading only | Immediate recall | Delayed, closed-book reconstruction |
| Repair | Generic “review again” | Topic-level retry | Diagnoses and repairs the failed dependency |
| Confidence safety | Overstates mastery | Adds a caveat | Separates evidence, uncertainty, and next test |

## Interpretation

- **15 to 18:** strong candidate for `completed/`
- **11 to 14:** useful sample, repair weak dimensions
- **6 to 10:** substantial redesign needed
- **0 to 5:** polished output may be masking a missing learning system

These thresholds are internal quality controls, not validated psychometric cutoffs.
