# Rubric: Error taxonomy and repair

Use one primary cause per failed attempt. Add a secondary cause only when necessary.

| Error type | Diagnostic question | Smallest useful repair | Verification |
|---|---|---|---|
| Concept | Is the definition or mechanism missing? | Rebuild from the prerequisite and one counterexample | Explain it and solve a direct problem |
| Interpretation | Was the question or diagram read incorrectly? | Mark givens, target, units, and qualifiers | Solve a differently worded isomorphic problem |
| Method selection | Was the wrong rule or algorithm chosen? | Build a trigger and anti-trigger comparison | Choose methods across a mixed set |
| Calculation | Was the approach right but execution wrong? | Isolate the arithmetic or algebra pattern | Timed short drill with checkpoints |
| Recall | Was known material unavailable without cues? | Closed-book prompt plus spaced retest | Retrieve after delay |
| Time or selection | Was effort spent where expected return was low? | Add a stop rule and triage threshold | Use it in the next timed set |
| Risky guess | Was confidence uncalibrated? | Record confidence before checking | Compare confidence with accuracy over several tests |

## Closure rule

An error is not closed when the old answer is understood. It is closed when a different problem is solved correctly after a delay without the previous solution visible.
