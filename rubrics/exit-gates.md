# Rubric: Exit gates

## Concept exit gate

- [ ] I can state the motivating problem.
- [ ] I can draw or narrate the mechanism.
- [ ] I can derive or justify the exact rule.
- [ ] I can name assumptions and a boundary case.
- [ ] I can solve one direct problem.
- [ ] I can select the method in a disguised problem.
- [ ] I can retrieve the core model without notes.
- [ ] I have repaired the most recent error on a new problem.

## Subject exit gate

- [ ] The authoritative scope is mapped.
- [ ] Available past questions are attempted and tagged.
- [ ] A closed-book concept map exists.
- [ ] Formula notes include conditions, not only expressions.
- [ ] A timed subject test meets the chosen threshold.
- [ ] Every wrong answer has a cause and preventive rule.
- [ ] No unresolved repeated conceptual error remains.

## Product release gate

- [ ] Human and AI roles are disclosed.
- [ ] Observable artifact facts are separated from outcome claims.
- [ ] Sources and evidence dates are visible where needed.
- [ ] Personal or confidential data is absent.
- [ ] Rights and license boundaries are stated.
- [ ] A reviewer can reproduce the evaluation using this repository.
