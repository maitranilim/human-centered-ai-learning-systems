# Sample: Digital Logic learning loop

## Learning objective

Build durable conceptual ownership rather than recognition from rereading.

## Loop

1. **Curiosity:** Begin with the question the concept exists to answer.
2. **Picture:** Show the physical or logical mechanism.
3. **Rule:** State the exact relationship with assumptions.
4. **Problem:** Use the rule in a worked example, then fade support.
5. **Retrieve:** Close the page and reconstruct the idea.
6. **Repair:** Diagnose the failed step and revisit only that dependency.

## Minimal session

- Study the picture and labels.
- Read the exact rule.
- Cover it and restate it in plain language.
- Attempt one memory lock.
- Mark the specific gap if retrieval fails.

## Quality check

The learner should be able to answer all four:

- What problem does the idea solve?
- What mechanism makes the rule true?
- What assumption or boundary can break it?
- Can I solve a new problem without copying the example?
