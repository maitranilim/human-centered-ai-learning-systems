# Sample: Computer Networks visual recall loop

## Learning objective

Compress a large syllabus into mechanisms that can be reconstructed under exam pressure.

## Twenty-minute loop

| Time | Action | Observable output |
|---:|---|---|
| 1 minute | Study the picture | Point to the moving object, boundary, or state change |
| 6 minutes | Read one concept | Explain the mechanism without copying |
| 3 minutes | Teach it aloud | Use protocol names and units precisely |
| 7 minutes | Solve one problem | Transfer the mechanism to a calculation or trace |
| 3 minutes | Mark one mistake | Name the failed concept, method, or decision |

## Retrieval sequence

Use the same topic in four passes:

1. immediate cover-and-recall;
2. same-day problem;
3. 24-hour reconstruction;
4. later mixed retrieval.

The diagram is useful only if it lets the learner predict what changes, what stays end-to-end, and which layer owns the decision.
