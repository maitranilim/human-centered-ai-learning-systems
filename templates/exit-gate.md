# Exit gate

Use this gate before progressing from a topic or completion block.

- [ ] Scope is mapped to an authoritative source.
- [ ] The learner can explain the mechanism without copying.
- [ ] Rules include assumptions, units, and boundary conditions.
- [ ] At least one worked example has been transferred to a nearby problem.
- [ ] A closed-book reconstruction has been attempted.
- [ ] Errors are classified before more content is replayed.
- [ ] A delayed retest is scheduled.
- [ ] Remaining uncertainty and untested assumptions are recorded.

Progression is evidence-based. It is not a guarantee of an exam score, rank, or other outcome.
