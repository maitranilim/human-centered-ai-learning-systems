# Contribution log

This is an append-only record of human directions that materially changed an AI-assisted learning system.

## Entry format

Each entry should contain:

- date or date range;
- learning problem;
- prior model behavior or risk;
- human direction;
- resulting behavior;
- preserved evidence;
- evidence level;
- reuse rule;
- limitations.

## Evidence levels

- **A:** directly visible in an artifact.
- **B:** recoverable repeated instruction in available interaction history.
- **C:** retrospective synthesis, clearly labeled.

Raw private conversations are not required. Preserve the smallest evidence needed to make the contribution credible and reproducible.
