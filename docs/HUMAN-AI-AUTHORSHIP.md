# Human-AI authorship

## Plain-language disclosure

These artifacts were produced through substantial collaboration with ChatGPT and Codex. `maitranilim` did not manually write every sentence, draw every diagram, or implement every production step.

`maitranilim` owned the learning problems, constraints, pedagogical direction, iterative critique, evaluation criteria, selection, and acceptance decisions. ChatGPT and Codex performed substantial drafting, synthesis, generation, layout, and implementation work.

## “Teacher and student” interpretation

The most defensible analogy is that `maitranilim` acted as the teacher of the interaction:

- noticed where the model produced shallow or misleadingly polished work;
- supplied a better mental model and acceptance rule;
- asked for another attempt;
- inspected whether the behavior improved;
- kept reusable instructions that worked.

This changed the model’s behavior within the work and improved `maitranilim`’s reusable workflow. It does not establish that the base model permanently learned from these conversations.

## Credit rule

A human contribution is logged when it changes one or more of:

- problem definition;
- pedagogical sequence;
- factual or safety constraint;
- evaluation criterion;
- visual explanation;
- repair logic;
- selection or rejection decision;
- reusable workflow.

Merely requesting “make it better” is weak evidence. A precise critique that produces a reproducible behavior change is strong evidence.
