# Contribution taxonomy

This vocabulary makes human direction legible without overstating manual authorship.

| Contribution | Operational definition | Evidence to preserve |
|---|---|---|
| Problem framing | Defines the learner, obstacle, desired behavior, and constraints | Initial brief, learner profile, rejected assumptions |
| Specification ownership | Converts a broad goal into requirements and exclusions | Checklist, protocol, acceptance criteria |
| Pedagogical architecture | Orders concepts, examples, retrieval, transfer, and repair | Learning map, dependency graph, lesson pattern |
| Instructional systems design | Connects content, practice, assessment, and feedback over time | Study loop, schedule, revision system |
| Iterative supervision | Reviews model work and gives directional corrections | Before/after output, critique, change log |
| Evaluation design | Defines what counts as a good explanation or successful exit | Rubric, test, threshold, counterexample |
| Error analysis | Classifies why an answer or process failed | Error taxonomy, mistake ledger, repair mapping |
| Multimodal art direction | Specifies how text and diagrams divide explanatory work | Visual brief, diagram correction, layout decision |
| Curation | Selects, organizes, and contextualizes outputs | Inclusion decision, folder taxonomy, artifact notes |
| Provenance design | Makes roles, sources, uncertainty, and rights visible | Authorship statement, manifest, license map |

## Strength of evidence

| Level | Meaning |
|---|---|
| A: artifact-backed | The requirement or result is directly visible in a preserved artifact |
| B: conversation-backed | A repeated instruction or correction is recoverable from available interaction history |
| C: retrospective synthesis | A plausible pattern inferred across work, clearly labeled as reconstruction |

The contribution log should prefer Level A, distinguish Level B, and never present Level C as a verbatim historical record.
